# baseproject

Este projeto é uma base para desenvolvimento de aplicações Java com Spring Boot, voltada para a criação de APIs REST seguras e escaláveis.

A estrutura contempla uso de Spring Web, Spring Data JPA, PostgreSQL, Spring Security, autenticação via JWT, migrações com Flyway e documentação da API com OpenAPI/Swagger. O objetivo principal é servir como ponto de partida para novos sistemas, acelerando a configuração inicial e padronizando a arquitetura do backend.

## Tecnologias principais

- Java 21
- Spring Boot 4
- Maven
- Spring Web
- Spring Data JPA
- PostgreSQL
- Spring Security
- JWT
- Flyway
- OpenAPI / Swagger

## Objetivo

Fornecer uma base sólida para construir serviços backend com autenticação, persistência em banco relacional e boas práticas de desenvolvimento em Java.
